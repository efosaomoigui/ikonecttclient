# Client-supplied people-photo source

This folder is the authoritative source for new people photography for Options A and E. The client designs and supplies these images. Do not generate people photos or change subjects, clothing, furniture, devices or environments. Preserve every original file.

Only create delivery copies through proportional resizing, encoding and explicitly documented crops. Keep scenes vivid, with narrow fades only where text meets photography. Use varied people, interiors and devices rather than repeating the same sofa, person or laptop.

New files are reviewed and mapped deliberately to relevant sections. Adding a file does not automatically install it everywhere. Do not remove approved hero photographs without the client's direction.

Current placements and the next image brief: docs/CLIENT_IMAGE_LIBRARY_REVIEW.md at the repository root. Source hashes, image dimensions and export records: assets/review/client-library/exports.json. Website assets: assets/visual-library/client-library/. Review gallery: assets/review/client-library/index.html.
