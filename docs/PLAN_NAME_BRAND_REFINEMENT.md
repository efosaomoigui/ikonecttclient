# Plan-name brand refinement

27 October 2026 · Active Templates A and E.

Only the leading `i` in residential plan headings is visually replaced with the official dot-and-lightning symbol, followed by a dash: i-Basic, i-Silver, i-Gold, i-Platinum and i-Diamond. The symbol and dash are red on A's white cards and soft white on E's dark surfaces. The existing name typography, card surfaces, size, padding, borders and corner shapes are unchanged. No flyer-style banners are introduced.

Uses the existing native official-symbol mask. Catalogue records, prices, IDs, URLs, form values and support conversations remain unchanged. The presentation follows carousel audience changes and route updates, including catalogue cards, detail headings and comparison column headings. Archived B/C/D are excluded.

Validation: production build passed; 81 existing relevant tests passed; eight browser checks passed across A/E at 1440, 768, 390 and 320px. Measurements before/after removing the decoration confirmed identical padding, radius and typography, with no meaningful dimension change (less than 0.1px floating-point tolerance). Verified audience switching, catalogue/detail navigation, symbol colours, loaded mask, no page errors and no horizontal overflow.
